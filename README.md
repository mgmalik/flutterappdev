# 🚀 IS487 – Emerging Topics in Information Systems (Mobile Development with Flutter)

Welcome to the official GitHub repository for **IS487**, a course offered at **Prince Sultan University** under the **College of Computer & Information Sciences**. This repository contains lecture materials, code examples, projects, and resources for learning **cross-platform mobile app development using Flutter**.

## 📚 Course Overview

This course introduces students to modern mobile development practices using **Flutter**, Google's UI toolkit for building natively compiled applications for mobile, web, and desktop from a single codebase. Topics range from foundational concepts to advanced UI/UX design, state management, multi-screen navigation, and device integration.

## 🛠️ Technologies Covered

- **Flutter** – UI toolkit for building beautiful, natively compiled apps
- **Dart** – Programming language used in Flutter
- **Material Design** – UI/UX guidelines and components
- **VS Code / Android Studio** – Development environments
- **Git & GitHub** – Version control and collaboration

## 📖 Learning Outcomes

By the end of this course, students will be able to:

- Understand the Flutter widget tree and composition model
- Build responsive and adaptive UIs using Scaffold, Rows, Columns, and Containers
- Implement stateful and stateless widgets
- Create multi-screen apps with navigation and routing
- Work with device features (camera, storage, sensors)
- Publish apps to Google Play Store and Apple App Store
